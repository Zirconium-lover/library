# Физическое материаловедение, том 1 — переработанное изложение (LaTeX)

Переписанный «человеческим языком» первый том кафедрального учебника

> *Физическое материаловедение: Учебник для вузов: в 6 т.* / Под общ. ред. Б. А. Калина.
> Т. 1. Физика твёрдого тела / Г. Н. Елманов, А. Г. Залужный, В. И. Скрытный,
> Е. А. Смирнов, В. Н. Яльцев. — М.: МИФИ, 2007. — 636 с.
> (исходный PDF в корне репозитория: `31280_827c57aae36b2268c672a0ff899fd5af.pdf`).

Содержание учебника сохранено, но текст написан заново:

* материал разбит на короткие смысловые шаги, выводы расписаны по шагам;
* роль каждого фрагмента видна по цветному блоку: определение, главная мысль,
  физический смысл, числовой пример, «осторожно», необязательное «подробнее»;
* каждый раздел начинается с ориентира («о чём раздел») и заканчивается
  конспектом и вопросами для самопроверки; в конце главы — ответы, задачи с
  ответами, сводка формул;
* иллюстрации нарисованы заново (TikZ/pgfplots); часть рисунков рассчитана
  физически (положения атомов около дислокаций — по теории упругости,
  кривые закалки — численным интегрированием);
* найденные опечатки и ошибки оригинала исправлены и отмечены сносками
  «**Исправление**».

Нумерация глав и разделов совпадает с оригиналом (удобно читать параллельно),
нумерация рисунков, формул и таблиц — своя.

## Сборка

Нужен TeX Live (2022+) с XeLaTeX; используются шрифты Libertinus (входят в TeX Live).

```bash
cd fizmat-tom1
make glava2        # только глава 2 -> pdf/glava2-defekty.pdf
make all           # весь том (готовые главы) -> pdf/fizmat-tom1.pdf
# или напрямую:
latexmk -xelatex glava2.tex
```

**Overleaf:** загрузить папку `fizmat-tom1`, в меню *Settings → Compiler*
выбрать **XeLaTeX**, основной файл — `glava2.tex` (или `main.tex`).

## Структура

```
fizmat-tom1/
├── fizmat.sty          стиль: шрифты, цвета, блоки, макросы, генераторы рисунков
├── frontmatter.tex     титул и «Как пользоваться этой книгой»
├── glava2.tex          сборка главы 2 отдельно
├── main.tex            сборка всего тома
├── chapters/ch2/       глава 2, по файлу на пункт (200-…, 211-…, …, 290-итоги)
├── figures/            сгенерированные рисунки (не править вручную)
├── tools/              скрипты: генерация рисунков, поиск переполненных строк
└── pdf/                собранные PDF
```

### Смысловые блоки (окружения из `fizmat.sty`)

| Окружение | Назначение |
|---|---|
| `orientir` | «О чём этот раздел» — в начале раздела |
| `opredelenie` | определение нового понятия |
| `keyeq` | ключевая формула (нумерованная, в рамке) |
| `glavnoe` | главный вывод |
| `smysl` | физический смысл, интуиция, аналогия |
| `primer` | числовой пример |
| `vnimanie` | типичная ошибка / тонкое место |
| `podrobnee` | необязательный материал (длинные выводы) |
| `itogi` | конспект раздела |
| `proverka` | вопросы для самопроверки |
| `\ispr{…}` | сноска об исправлении ошибки оригинала |
