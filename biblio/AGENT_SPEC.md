# Спецификация для поисковых субагентов библиографа

Прочти `biblio/TASK.md` (правила, коды подтем). Здесь — только формат вывода и приёмы.

## Доступ
- Работает только **WebSearch**. OpenAlex, Crossref, doi.org, Springer, Semantic Scholar закрыты
  (403 / ENOTFOUND) — не пробуй их. WebFetch почти везде закрыт; не трать на него попытки.
- Поэтому уровень проверки DOI почти всегда `V1`: DOI виден в выдаче поиска **именно для этого названия**.
  Выдача поиска пересказана моделью: принимай DOI, только если он явно привязан к этому названию
  (в URL результата вида doi.org/…, sciencedirect …/pii/… не считается DOI!, или в тексте рядом с названием).
  При малейшем сомнении — второй поиск по самому DOI в кавычках (`"10.1016/j.jnucmat.2013.01.xxx"`);
  если и он не подтверждает название — строка в `.unverified.csv`.
- **Никогда** не выводи DOI из PII ScienceDirect, номера тома или шаблона. Не дописывай DOI по памяти.
- НИРС («НИРС Ильясов Р.А. М25-109.pdf») не источник: не брать оттуда ни ссылок, ни чисел.

## Вывод (файлы, модуль csv Python, UTF-8, с заголовком)
1. `biblio/parts/<TAG>.csv`, колонки:
   `direction,subtopics,year,title,authors,journal,type,doi,doi_check,access,summary_ru,useful_for,values,values_source,priority,url,notes,pdf_in_library`
   - `direction`: 1/2/3 или «2;3». `subtopics`: коды через «;», например `2.1;2.2`.
   - `authors`: «Фамилия И.; Фамилия И.; …» (до 6, затем «et al.»).
   - `type`: эксперимент / модель / численный метод / обзор / данные / книга / диссертация.
   - `doi`: нижний регистр, без https://doi.org/. Без DOI — только книги/отчёты/диссертации с `doi_check=no-doi` и URL/ISBN/handle.
   - `access`: OA / closed / ?.
   - `summary_ru`: 2–4 предложения по-русски: что сделано, главный результат, чем полезно мезомодели
     (матрица Zr с вязким повреждением + градиентная регуляризация, хрупкие гидриды, когезионная граница гидрид–матрица, CalculiX).
   - `useful_for`: конкретно — параметр / закон / алгоритм.
   - `values`: (для направления 2) числа с единицами и условиями: «K_IC δ-ZrH1.66 = 3.3±0.4 МПа·м^1/2 (микроконсоли, 20 °C)».
     Несколько — через « | ». `values_source`: abstract / fulltext / snippet.
   - `priority`: A / B / C. `url`: ссылка, где видел (страница издателя или репозиторий). `notes`: что сомнительно.
2. `biblio/parts/<TAG>.needs.csv`: `doi,title,what_to_extract` — что нужно из полного текста (таблицы, кривые, параметры).
3. `biblio/parts/<TAG>.unverified.csv`: `title,authors,year,journal,why,where_seen` — интересное без подтверждённого DOI.

Пиши строки в файл по мере работы (дописывая), а не в ответ. Перед записью проверь, нет ли уже такой
записи в `biblio/catalog.csv` и в своих файлах (по DOI и названию). Дубли с другими подтемами допустимы —
основная сессия сольёт их.
Финальный ответ основной сессии — коротко: сколько строк, сколько V1/V2, пробелы. Без строк CSV.

## Параллельная работа
- Временные файлы и скрипты — только в своей подпапке scratchpad с именем TAG (`.../scratchpad/<TAG>/`);
  чужие файлы не запускать и не трогать.
- Лимит WebSearch — 200 вызовов на ход **на всех агентов сразу**. Не трать поиски на перебор:
  один точный запрос «название + doi», второй — только для проверки сомнительного DOI.
- Приёмы, давшие DOI: WebSearch с `allowed_domains` (`tandfonline.com`, `onlinelibrary.wiley.com`,
  `researchgate.net`, `ascelibrary.org`, `iopscience.iop.org`, `mdpi.com`, `jstage.jst.go.jp`, `elibrary.ru`,
  `link.springer.com`, `sciencedirect.com`) — DOI часто виден прямо в URL. Поиск по строке DOI в кавычках почти не работает.
