# Управление по пути: формулы и эталоны со snap-back

## 1. Ограничения из литературы

Обозначения: $\lambda$ — множитель нагрузки, $\hat f$ — опорный вектор нагрузки, $a$ — перемещения,
индекс 0 — последнее сошедшееся состояние.

| источник | ограничение $g(a,\lambda)=0$ | область применимости |
|---|---|---|
| Gutiérrez 2004, CNME 20:19, ур. 12–18, 23 | $\tfrac12\hat f^T(\lambda_0\Delta a-\Delta\lambda\,a_0)-\Delta\tau=0$ | повреждение с **секущей** разгрузкой, малые деформации; $V=\tfrac12a^T\lambda\hat f$ (ур. 13) |
| Verhoosel, Remmers, Gutiérrez 2009 (IJNME 77:1290), разд. 2.1.1, ур. 23–25 | то же; $\partial g/\partial a=\tfrac12\lambda_0\hat f^T$, $\partial g/\partial\lambda=-\tfrac12\hat f^Ta_0$ | повреждение |
| Verhoosel 2009, разд. 2.1.2, ур. 26–33 | $g=\Delta a^T(\lambda_0\hat f-f^*_0)-\Delta\tau$, $f^*=\int B^TC^TD_e^{-1}\sigma\,d\Omega$; $\partial g/\partial\lambda=0$ | **пластичность**: разгрузка параллельна упругой |
| Verhoosel 2009, разд. 3.4, ур. 75–77 | шаг: $\Delta\tau_i=\Delta\tau_{i-1}(k_{opt}/k_{i-1})$ или $(1/2)^{(k_{i-1}-k_{opt})/4}$, сглаживание по 3–4 шагам, $k_{opt}=5$ | |
| Verhoosel 2009, разд. 3.3, 4.1 | старт с управления силой; переход на энергию, когда рассеяние за шаг больше порога (у них $10^{-8}$ Н·мм); обратный переход возможен | |
| Börjesson et al. 2022, Comput. Mech. 70:437, ур. 14–18 | $\varphi=\int_\Omega\Delta\mathcal D\,d\Omega-\Delta\tau$, $\mathcal D$ — удельное рассеяние в точке (неявный Эйлер); $h_I=\int\frac{\partial\Delta\mathcal D}{\partial E}:\frac{\partial E}{\partial a_I}d\Omega$, $w=0$ | **любые** механизмы, их сумма; большие деформации. | Lorentz & Badel 2004, IJNME 60:499 | ограничение по максимуму упругого предиктора функции текучести; сильно нелинейно, нужен свой алгоритм (аннотация) | отличает чисто упругую разгрузку от рассеивающего пути |
| Hellweg & Crisfield 1998, C&S 66:705 | цилиндрическая длина дуги с новым правилом выбора корня; для резких snap-back в DCB с интерфейсом | |

## 2. Замечание к `pathfollow.c` (вывод мой)

В коде реализовано ограничение Gutiérrez/Verhoosel для **секущей** разгрузки
($dG=\tfrac12(\lambda_nP-\lambda P_n)$). В модели ccx повреждение связано с пластичностью, разгрузка
идёт параллельно упругой (до разрушения $D<1$), а для такого случая у Verhoosel отдельная форма (разд. 2.1.2).
Чем это грозит, покажу на 1D: пусть $a=a_p+\lambda/k$, чисто упругая разгрузка $\dot a=\dot\lambda/k$. Тогда
$$G_{\text{секущ}}=\tfrac12\hat f(\lambda\dot a-\dot\lambda a)=-\tfrac12\hat f\,\dot\lambda\,a_p>0\quad\text{при }\dot\lambda<0.$$
Секущее ограничение видит **ложное рассеяние на упругой разгрузке** пластически деформированного тела. Шаг можно
«выполнить», просто разгружаясь упруго, — решатель уходит с ветви разрушения на ветвь разгрузки. Лекарства:
форма Verhoosel 2.1.2 (с $f^*$) или Börjesson (сумма $\Delta\mathcal D$ по точкам:
$\Delta\mathcal D=(1-D)\sigma_{\text{eff}}:\Delta\varepsilon_p+Y\Delta D$, $Y=\tfrac12\varepsilon_e:C:\varepsilon_e$ — для модели ccx, мой вывод).
Тест ниже (Б1-snap-back) это различит.

## 3. Эталоны со snap-back (аналитика)

**(а) Брусок Б1** (`nonlocal-benchmarks.md`, разд. 1; локальная модель — то же при $\varphi=$ один элемент). Параметрически по раскрытию $a$:
$$F=A\sigma_y(1-a/u_f),\qquad \Delta=a+\frac FA\int_0^{L_b}\frac{dx}{E(1-D(x))}.$$
Для локальной полосы шириной $h$: $\Delta=a+\frac{F}{AE}(L_b-h)+h\sigma_y/E$. Snap-back при $L_b>Eu_f/\sigma_y$ (плюс $h$).
Пример: $E=2\cdot10^5$, $\sigma_y=400$, $u_f=0{,}02$ → $Eu_f/\sigma_y=10$; брусок $L_b=30$ даёт snap-back с
$d\Delta/da=1-\sigma_y(L_b-h)/(Eu_f)\approx-2$. **Проверка:** точки $(F,\Delta)$ решения лежат на кривой;
$\int F\,d\Delta=A(G_f+h\sigma_y^2/(2E))$ (при $\varepsilon_{p,i}\to0$, $H=0$). Рассеяние на шаге с ложным
упругим ходом (разд. 2) проявится как отход от кривой в сторону упругой прямой $F=AE(\Delta-a_p)/L_b$.

**(б) Стержень + когезионный слой** (`cohesive-uc6.md`, разд. 1; Hamitouche et al. 2008, ур. 19):
$u=\delta+TL/E$, snap-back при $L/E>(\delta_f-\delta_0)/T_{n0}$. Кривая: $T(\delta)$ — билинейная, $u(\delta)$ — по формуле.
С вязкостью — Hamitouche, ур. 23–27, Gao & Bower 2004, рис. 4.

**(в) Перфорированная балка, мезо-примеры** — Verhoosel 2009, разд. 4 (только опубликованные кривые, аналитики нет).

## 4. Рекомендации для ccx (из разд. 1)

- Старт — управление силой или перемещением, переход на энергетическое ограничение по порогу рассеяния
  за шаг (Verhoosel, Börjesson).
- Для модели «пластичность + повреждение» брать рассеяние по точкам (Börjesson, ур. 15–16), а не секущее.
- Шаг $\Delta\tau$ регулировать по числу итераций (Verhoosel, ур. 75–77; Börjesson, ур. 17–18).
- `crackcontrol.c` — локальный вариант по раскрытиям (Alfano & Crisfield 2003; Segurado & LLorca 2004).
  Он хорош, когда зона разрушения известна заранее (интерфейсы гидридов), но требует выбора
  контролируемых степеней свободы (Gutiérrez 2004, с. 21 — недостаток метода indirect displacement control).
